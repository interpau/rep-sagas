# Catálogo de sagas cinematográficas

Este repositorio contiene un catálogo de diferentes sagas
de películas, organizado mediante archivos de texto.

Cada saga dispone de un archivo de prólogo con información
sobre su historia y un archivo con el listado de sus películas.

El objetivo del proyecto es practicar el uso de Git y GitHub,
gestionando versiones y sincronizando repositorios locales
y remotos.
